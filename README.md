# Galería de Títulos y Certificaciones

Bienvenido a mi galería de títulos y certificaciones como Ingeniero de Software.  
Aquí podrás encontrar una recopilación de mis logros académicos y profesionales, organizada de manera clara para mostrar mi formación y competencias.

## Contenido
- Títulos académicos
- Certificaciones profesionales
- Cursos relevantes

## Herramientas
- HTML
- CSS
- JAVASCRIPT

## LIBRERIAS
- PDF VISOR: Libreria para mejorar la visualizacion de los pdfs

## Instrucciones para usar este proyecto
1. **Visualizar la galería**:  
   Abre `index.html` (si es un proyecto web) en tu navegador para explorar los títulos y certificaciones.

2. **Agregar nuevos documentos**:  
   - Coloca los archivos en la carpeta `/assets/pdf`  
   - Actualiza `index.html`en la clase `item` y en la carpeta(`pdf`) debe incluir el nuevo título o certificación en fomato pdf y para la imagen debe pasarla a fomato png/jpge/jpg.
